Algorithm Architecture & Mathematical Formulation

Academic Research
01

Watermark Multi-Domain Scrambling (DWT + DCT + Hessenberg + SVD)

The copyright watermark $W \in \mathbb{R}^{32 \times 32}$ is decomposed via 2D Haar DWT into subbands. The low-frequency approximation subband $LL$ is converted into the frequency domain via 2D DCT. We perform an upper Hessenberg reduction $LL_{\text{dct}} = Q H Q^T$, followed by Singular Value Decomposition $H = U S V^T$. The singular values trace $S = \text{diag}(s_1, \dots, s_n)$ generates a fingerprint fused with the secret key $K$ via MD5 hashing to create a chaotic permutation sequence $\pi$, scrambling $W$.

02

Host Mid-Frequency 8×8 DCT Embedding

The cover image is partitioned into non-overlapping $8 \times 8$ blocks. For each block, 2D Discrete Cosine Transform (orthonormal) is computed. Bits from the scrambled watermark are modulated into mid-frequency coordinates $(3,3), (3,4), (4,3), (4,4)$ via sign modulation:
d[u,v] = |d[u,v]| + α  (if bit = 1)  /  -(|d[u,v]| + α)  (if bit = 0)
Applying 2D Inverse DCT (IDCT) reconstructs the watermarked image with high PSNR ($\approx 42.5$ dB).

03

Blind Watermark Extraction & Host Separation

Extraction requires only the watermarked image and secret key (pure blind recovery). The sign of DCT mid-frequency coefficients extracts the bit sequence ($b = 1$ if $d[u,v] > 0$, else $0$). The permutation $\pi$ is inverted to reconstruct the original watermark. Simultaneously, the host image is separated by reversing the additive strength bias: d_{\text{restored}}[u,v] = \text{sgn}(d[u,v]) \times \max(0, |d[u,v]| - α), achieving flawless separation of both assets!
